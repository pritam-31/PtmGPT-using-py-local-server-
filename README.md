# PtmGPT ( using py-local-server )
PtmGPT is a secure, web-based multimodal medical AI assistant. Powered by a local Python inference server, it integrates the MedGemma 4B model—trained on diverse clinical datasets including Radiology, Dermatology, Pathology, and EHR. It securely processes medical text and images on-device, featuring a modern UI, Node.js bridge, and secure auth.
